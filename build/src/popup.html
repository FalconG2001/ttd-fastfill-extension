If TTD is already showing a queue or countdown, do not reload the tab. FastFill can attach and start watching the existing page.

      

    


    

      
Booking search

      
Temple and Seva are taken from the TTD page exactly as currently selected when you press Start. FastFill does not switch these dropdowns.

      
Preferred dates

      

      FastFill tries dates from top to bottom.

      
Preferred times

      

      For each date, FastFill tries times from top to bottom. If the selected seva has no time slots, FastFill ignores this list and books the date/ticket directly.
      

      

        
        
      

      
      
TTD decides the real number of pilgrim rows after Continue. FastFill uses that row count, so a request for 4 can safely continue with 2 if TTD only allows 2.

      

        
        
      

      
    


    

      
Failure recovery

      
      
      
Each date/time combination is attempted at most once. FastFill does not hammer the same failed slot repeatedly.

    


    

      
General details

      
Some TTD sevas ask for booking-level details before pilgrim rows. Fill these once so FastFill can enter them immediately when the fields appear.

      
      
      

        
        
        
        
        
      

      
        
        
        
        
        
        
        
        
      
      
For a normal Gothram text field, FastFill uses exactly what you saved. If TTD ever uses a dropdown, FastFill reads TTD's real options and can match close spellings. Ambiguous matches ask you instead of guessing.
